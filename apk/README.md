# Medikal Android

اپلیکیشن Native اندروید سامانه درمانی Medikal با Kotlin و Jetpack Compose. پروژه در پوشه `apk` و در کنار بک‌اند `src` قرار دارد.

## امکانات

- ورود با موبایل/OTP و ایمیل، نگهداری نشست Sanctum و خروج امن
- داشبورد فارسی RTL با پس‌زمینه سفید و خاکستری، متن مشکی و اکشن‌های ذغالی
- فهرست پزشکان، تخصص‌ها، جزئیات و رزرو نوبت
- نوبت‌های من، نسخه‌ها، پرونده پزشکی، کیف پول و پرداخت‌ها
- داروخانه‌ها، آزمایشگاه، گفتگوها و اعلان‌ها
- دستیار هوش مصنوعی پزشکی متصل به `v1/chat/medical/ask`
- پزشک در خانه/درخواست اعزام متصل به Emergency API
- آدرس API قابل تنظیم برای توسعه، شبکه داخلی و محیط Production
- حالت آفلاین پیش‌فرض با پزشکان، نوبت‌ها، داروخانه، آزمایشگاه، نسخه‌ها، کیف پول، پرونده و پاسخ اولیه هوش مصنوعی
- کلید تغییر فوری بین داده‌های استاتیک و API سرور در صفحه «بیشتر»

## اجرای محلی

پیش‌نیازها: Android Studio، JDK 17 و Android SDK 35.

1. پوشه `apk` را در Android Studio باز کنید.
2. Sync Gradle را اجرا کنید.
3. بک‌اند را روی پورت `8210` بالا بیاورید.
4. برای Emulator از آدرس پیش‌فرض `http://10.0.2.2:8210/api/` استفاده کنید.
5. برای گوشی واقعی، در بخش «بیشتر ← تنظیمات اتصال» IP سیستم را وارد کنید؛ مثال: `http://192.168.1.10:8210/api/`.

ساخت APK دیباگ:

```bash
./gradlew assembleDebug
```

خروجی در `app/build/outputs/apk/debug/app-debug.apk` قرار می‌گیرد.

## معماری

- `MainViewModel`: وضعیت مرکزی، عملیات کاربر و هماهنگی صفحه‌ها
- `ApiClient`: کلاینت سبک JSON با timeout، Bearer token و خطای استاندارد
- `SessionStore`: ذخیره نشست و آدرس API
- `ui/theme`: تم تک‌رنگ و طراحی Material 3

> پاسخ هوش مصنوعی صرفاً راهنمای اولیه است و جایگزین پزشک یا تماس با اورژانس ۱۱۵ نیست.
